Apredendo sobre elementos textuais

o que são os elementos texxtuais?

os elementos textuais serve para destacar, ou dar significado a pates especificas do conteudo

Elementos strong

È muito importante aprender a estrutura do HTML.

a tag strogn é utilizada para indicar que determinado trecho possui forte improtancia.

Elementos b

Aprenda HTML , CSS e JavaScript para criar páginas web.

A tag b (bold) também costuma deixar o texto em negrito, mas sua finalidade é criar apenas um estilo/destaque visual.

Elemento em

voce realmente precisa estudar

O elemento em comunica que aquele trecho deve receber uma determinada enfase dentro da frase.

Elemento i

O tempo software é utilizado com frenquéncia na área de tecnologia.
