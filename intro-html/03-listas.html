O que são lista no HTML?

Uma list é uma sequencia de itens relacionada entre si.

No THML, existem principalmente três tipos de lista , lista não ordernadas , lista ordernadas , e lista desccrita ,

lista não ordenada (ul)

Uma lista não é usada quando a orden elementos/itens não importa.

    >
  • Arroz
  • Feijão
  • Macarrão
  • Carne
  • Café

Lista ordenada (ol)

Usamos uma lista ordenada quando os itens possuem uma sequéncai, Uma classificação ou uma orden que precisa ser respeitada.

>
  1. Fercer a água
  2. Colocar o café no filtro
  3. Despejar a água lentamente
  4. Servir o café

Lista de decrição (dl)

Usamos uma lsita de descrição quando precisamos descrever algum termo.

Para criarmos essa lista, utilizimos três elementos:

  • dl(description): Representa a lista de descrição
  • dt(description) : Representa o termo.
  • dd(data description) : Representa a descrição do termo.
