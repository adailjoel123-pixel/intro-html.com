Sobre os diferentes tipos de imagens

Abaixo, temos uma lista dos diferentes tipos de imagens e quando usar:

  • JPEG/JPG : Bom para fotos de produtos, paissagem e fotos, pois, possui muitas cores e possui um arquivo relativamente pequeno. Não suporta transparencia e caso seja comprindo varias vezes, pode perder qualidade.
  • PNG : Excelente escolha quado queremos trasnparencia e preservar bastante a qualidade. Geralmente usamos para logos, imagens com transparencia, grafica simples.
  • webp : Formato moderno desenvolvido para a web. Muito menor que JPEG E PNG, mantém a qualidade da imagens pois suporta copressão sem perda. Usamos para qualquer imagem comun na web.
  • AVIF : Assim como o formato WEBP, é um formato moderno e tambem e capz de produzir arquivos bastante pequenos/leves mantendo uma qualidade. Geralmente usamos esse formato, qunado queremos priorizar performance.
  • SVG : O SVG é um elemnto vetorial, excelente para logos, icones, ulustrações, formas geometricas e graficos. A vantagem desse elementos, é que ele pode ser apliamdo.
