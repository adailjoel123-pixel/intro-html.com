Formulário HTML

O que são Formulário no HTML?

Os formulários são uma das parte masi importante do HTMl pois ajudam a introduzir uma ideia diferente.

O usário deixa de apenas consumir contéudo e passa a fonecer dados para o sistema.

Um formulário de froma resumida, é uma área da pagina destinada a coleta de informações.

Exemplo de uso:

  • login
  • Cadastro
  • Contato
  • Comentarios
  • Endereço
  • Inscrições em newsletter

Criando um formulario basico

  • < labe < : Representa um rótulo/etiqueta para um campo. È um recurso fundametal para a acessebilidade.
  • for : Para conectarmos o nosso rótulo (label) ao input, utilizamos o atributo for. Ele serve para criar a relação com o id do input.
  • type : Esse atributo serve para definimos o tipo de input que desejamos apresentar para o usario com base no dado queremos coletar.
